Positioning

A canvas, not a script.

Mythrun is an AI-powered multiplayer platform for playing D&D 5e in small groups. The AI handles DM logistics, world-building scaffolding, and rule lookups — players get to be players. The brand's job is to position that product as literary, patient, and craft-conscious: a tool for collaboratively-authored fiction, not a game that runs on rails.

  • Ghibli, not Marvel.Adventure and awe, contemplative rather than action-packed. Quiet moments carry weight.
  • Literary, not gamey.Closer to Le Guin, Tolkien, and Gene Wolfe than to video-game fantasy. Craft, writing, shared narrative.
  • Patient, not hyped.Gilligan / Severance pacing. Confident enough to be quiet. The opposite of typical AI-product marketing.

Tone test: if a brand decision feels too shiny, too loud, too AI-coded, or too game-coded, it's wrong for Mythrun. When in doubt, go quieter, smaller, more considered.

Usage rules:

· ember-600 is an accent, never a ground. A page full of ember elements dilutes the one color we have.

· Semantic colors (success / warning / danger / info) are for UI state only. Not for brand expression, marketing, or editorial.

Typography

Three typefaces, three scopes.

This pairing is a working first concept — good enough to ship with, committed so design and dev work isn't blocked on an open question. Revisit once the product is in real use. Tyma Garamont is locked as the wordmark typeface; Source Serif 4 and IBM Plex Mono are the working body and UI choices.

01 · Wordmark typeface · locked
Tyma Garamont Regular
MyFonts, $49 commercial license · wordmark-only · do not set body or UI in this typeface

Rendered from the exports in brand/wordmark/exports/ rather than typeset fresh. Tyma Garamont carries a warm, slightly handmade quality that matches the Parchment & Ink register; it does not belong anywhere outside the wordmark itself.

02 · Body / prose typeface · working pairing
Source Serif 4
Google Fonts · OFL license · use for prose, marketing body copy, document text, display headings

A long session in the quiet hours. Four friends, one AI narrator, a world that remembers you.

Serif body extends the literary register of the Tyma wordmark. Source Serif 4 is warm, readable at text sizes, and contemporary without being self-consciously design-y. It's the default for anything longer than a UI label — product copy, blog posts, marketing pages, document typography. When headline density becomes a problem later we'll revisit with a more characterful display companion.

03 · UI / data / monospace typeface · working pairing
IBM Plex Mono
Google Fonts · OFL license · UI chrome, data readouts, labels, code

Monospace in the UI expresses the computational honesty of the product: Mythrun runs on structured state — characters, rolls, scene graphs, logs — and monospace chrome makes that machinery legible instead of hiding it behind polished product-marketing typography.

Fira Code was considered and rejected. Great coding typeface, but the ligatures and slight expressiveness are too much for restrained product chrome. Fira Code remains the recommended personal dev-setup monospace for the team — it's just not the product's typeface. Full reasoning in brand/decisions.md.

Logomark

The pixel-art quill.

Two canonical resolutions: 64 (the default mark) and 32 (designed-at-size favicon). 128 was explored during ideation but is not in the production system.

128 logical · ideation
Archived brainstorming artifact in brand/history/ideation/. Reads too refined as pixel art; not a usable production variant.
64 logical · canonical
The default mark. Use everywhere the mark appears at 48 px and up. Scale with nearest-neighbor only.
32 logical · favicon
actual display size · 32px
Designed-at-size for browser favicons and bookmarks. Never upscale above 32 × 32.

Lockups

Stacked is primary. Horizontal is secondary.

In the stacked lockup the quill tip aligns with the gap between M and h — the mark dips into the word. That alignment is the reason the composition is strong; do not adjust mark position vertically.

Lockups are monochrome. The "primary" lockup variant is both elements in paper-900. The ember-mark / ink-wordmark dual-color version was tested and rejected as non-cohesive — it reads as two things placed near each other, not as a single composition.
